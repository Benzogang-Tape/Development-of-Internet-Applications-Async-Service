# Стих на тему курса "Разработка интернет-приложений"

Сначала были Figma и страница,
React нам собирал красивый вид.
Услуга в карточках теперь искрится,
Но без бэкенда SPA пока молчит.

В PostgreSQL таблицы мы создали,
Настроили модели, ORM.
По REST API мы данные подали,
А в Minio — картинки без проблем.

Включаем Redis, сессии и куки,
Чтоб модератор подтверждал заказ.
Заявка собрана без лишней муки,
И JWT-токен скрыт от глаз.

Но чтоб процесс закончить справедливо,
На расте асинхронный сервис шлёт ответ.
Сформировав колбэк неторопливо,
Он результаты выведет на свет.

Redux Toolkit все стейты обновляет,
Через Axios запрос опять летит.
Наш Tauri десктопы покоряет,
А PWA мобильный мир пленит!
